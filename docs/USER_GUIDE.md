# User guide

1. Serve the folder through HTTP using `python -m http.server 8080`.
2. Upload a PDF, DOCX or TXT file.
3. Enable **OCR every PDF page** for scans.
4. Keep **IPA form mode** enabled for IPA forms.
5. Select **Scan**.
6. Scroll continuously through every page.
7. Red boxes are selected; blue boxes are excluded.
8. Click a finding to jump to its page. Use Previous/Next or P/N.
9. Drag on a PDF page to add a manual box. Use **Clear manual boxes** if needed.
10. Download the findings CSV for an audit record.
11. Download the redacted PDF.
12. Open the exported PDF separately and inspect every page.

Check RefCom, Police ID, names, dates of birth, addresses, contact details, document numbers, signatures, handwriting, stamps, annotations and embedded images. DOCX pagination may differ from Word. Automated detection does not replace manual disclosure review.
